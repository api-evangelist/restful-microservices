An architectural style that structures an application as a collection of loosely coupled, independently deployable services that communicate via REST APIs using HTTP methods and standard web protocols. This collection covers RESTful microservices patterns, tools, service mesh technologies, API gateways, observability, and the ecosystem of frameworks and platforms for building, deploying, and scaling microservice architectures.
